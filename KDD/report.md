# KDD Report

**Dataset:** Credit Card Fraud Detection

**Selection & Preprocessing:** All records used; features standardised.

**Transformation & Data Mining:** Isolation Forest trained as an unsupervised anomaly detector.

**Evaluation:** Model produces predictions without using labels. When compared to ground truth, it detects many anomalies but also generates false positives.

**Expert Recommendations:** Explore deep learning based anomaly detection; adjust contamination parameter; combine unsupervised and supervised approaches.
