# Data Instructions

1. Install the Kaggle CLI and authenticate.
2. Run `kaggle datasets download blastchar/telco-customer-churn -p data/raw -f Telco-Customer-Churn.csv` from the project root.
3. Unzip if necessary and ensure the CSV resides at `data/raw/Telco-Customer-Churn.csv` relative to this README.
4. Record data provenance in the project notebook and README when refreshed.
