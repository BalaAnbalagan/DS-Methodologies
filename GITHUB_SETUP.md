## 🔐 GitHub Authentication

### Option A: Personal Access Token (Recommended)

If prompted for credentials:

1. Go to GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Click **Generate new token (classic)**
3. Give it a note: "DS Methodologies Portfolio"
4. Select scopes: Check **repo** (full control of private repositories)
5. Click **Generate token**
6. **COPY THE TOKEN** (you won't see it again!)
7. When pushing, use:
   - **Username**: Your GitHub username
   - **Password**: Paste the token (not your GitHub password)

### Option B: SSH Key (Alternative)

```bash
# Generate SSH key (if you don't have one)
ssh-keygen -t ed25519 -C "your_email@example.com"

# Copy public key
cat ~/.ssh/id_ed25519.pub

# Add to GitHub: Settings → SSH and GPG keys → New SSH key
# Use SSH URL instead:
git remote set-url origin git@github.com:YOUR_USERNAME/DS-Methodologies.git
git push -u origin main
```

## 🐛 Troubleshooting

### Error: "remote origin already exists"
```bash
git remote remove origin
git remote add origin https://github.com/YOUR_USERNAME/DS-Methodologies.git
```

### Error: "failed to push some refs"
```bash
# Pull first (if repo has files)
git pull origin main --allow-unrelated-histories
git push -u origin main
```

### Large File Warning
```bash
# Check file sizes
find . -type f -size +50M

# If you accidentally committed large files:
git rm --cached path/to/large/file
echo "path/to/large/file" >> .gitignore
git commit -m "Remove large file from tracking"
git push
```

### Update Git User Info
```bash
git config --global user.name "Your Actual Name"
git config --global user.email "your.email@example.com"

# Amend last commit with new author
git commit --amend --reset-author --no-edit
git push -f origin main
```
