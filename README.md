# DS Methodologies Portfolio

Three full data science project scaffolds demonstrating classic methodologies:

1. **CRISP-DM** — Telco churn mitigation (`crisp_dm_telco_churn/`)
2. **KDD** — Credit card fraud detection (`kdd_credit_fraud/`)
3. **SEMMA** — Bank marketing optimization (`semma_bank_marketing/`)

Each project includes:
- End-to-end Jupyter notebook (ready for Colab) following the methodology phase-by-phase.
- Medium article draft and 8–12 minute YouTube script.
- GPT-5/Claude critique prompts and sample revision logs (two passes per phase).
- FastAPI microservice + Dockerfile for deployment with placeholder artifacts.

## Dataset Links
- Telco Customer Churn: https://www.kaggle.com/datasets/blastchar/telco-customer-churn
- Credit Card Fraud Detection: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
- Bank Marketing Dataset: https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset

Authenticate with Kaggle CLI, then follow the `data/README.md` instructions within each project directory to download the required files.

## Quick Start
1. Pick a methodology folder and download the dataset into `data/raw/`.
2. Open the notebook under `notebooks/` and execute cells in order. Each section explains goals, inputs, outputs, and provides runnable code.
3. Capture visuals generated by the notebook and drop exported figures into the `assets/` subfolder.
4. After completing a phase, use the corresponding file under `prompts/` to drive two-pass GPT-5/Claude critiques. Update revision notes as you iterate.
5. Export trained pipelines to `app/artifacts/` and run the FastAPI service as described in each `app/README.md`.
